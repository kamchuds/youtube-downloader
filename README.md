# YouTube Downloader

A small Windows app: paste a YouTube link and save it as a high-quality MP4 or MP3.

**[Download the installer](https://github.com/kamchuds/youtube-downloader/releases/latest/download/YouTube-Downloader-Setup.exe)**

Windows may say "Windows protected your PC" because the installer isn't digitally signed. Click **More info**, then **Run anyway**.

The first time it opens, the app downloads the free tools it needs (yt-dlp, Deno and FFmpeg, about 170 MB). To get new versions, open **Settings** and click **Check for updates**.

Only download videos you have the rights to use. YouTube's terms restrict downloading.
